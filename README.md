# bettbox-compatible-bin-aur

AUR 包 [bettbox-compatible-bin](https://aur.archlinux.org/packages/bettbox-compatible-bin) 的 CI 管理仓库。

Bettbox 是一款使用 Mihomo (Clash Meta) 内核、基于 FlClash 早期版本进行重构的多平台代理客户端。

AUR PKGBUILD 以子模块形式托管在 [`aur/`](./aur) 目录下。
